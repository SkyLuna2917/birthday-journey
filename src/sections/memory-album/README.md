SECTION 04 — MEMORY ALBUM

This ZIP contains ONLY Section 04 (Memory Album), based on the supplied
"memory album.zip" design.

Files:
- index.html
- memory-album.css
- memory-album.js
- images/
- audio/

How to run:
1. Extract this ZIP.
2. Open index.html in Chrome/Edge.
3. Keep the image filenames in images/ when replacing photos.
4. Edit memory-album.js if you want to change the album text/content.

No npm or server is required for the standalone version.
