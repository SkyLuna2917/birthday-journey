# Section 01 — Main Page

Standalone development package for Birthday Journey Section 01.

## Run

```bash
npm install
npm run dev
```

## Scope

This package contains only the Main Page experience. The navigation buttons intentionally use temporary connector feedback; they are not wired to Sections 02–12 yet.
