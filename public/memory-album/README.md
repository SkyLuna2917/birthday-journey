# Photo Music Card
Replace `images/photo-1.jpg`, `photo-2.jpg`, `photo-3.jpg` with your photos.
Replace/add `audio/song-1.mp3`, `song-2.mp3`, `song-3.mp3`.
Edit the `message` values in `js/photo-card.js`.
Each photo has its own background song. Changing photos stops the previous song and starts the new one. Audio is stopped when leaving/hiding the page. No song name or music icon is shown.

Design: clean 2D layout with a fully transparent page background and a customizable gray card border.
